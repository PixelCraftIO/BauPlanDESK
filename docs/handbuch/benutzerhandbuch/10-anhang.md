## Häufige Meldungen und was zu tun ist

| Meldung / Beobachtung | Nächster Schritt |
| --- | --- |
| GRZ/GFZ ist ausgegraut | Rechtsgrundlage und BauNVO in den Rechtsgrundlagen speichern. Der Tooltip nennt den fehlenden Schritt. |
| „Ermittlung ist veraltet“ | Flurstücke und Zuordnungen prüfen, Baugrundstücke neu ermitteln und speichern. |
| Gebäude fehlt in GRZ/GFZ | Flurstückszuordnung, Gebäudetyp, Grundfläche und Geschosse im Gebäudemodell prüfen. |
| Aufmaßauswahl in einer Maske ist leer | Markierung auf Bedeutung, Zuordnung (Gebäude, Geschoss, Flurstück) und Höhensystem prüfen; Aufmaß speichern. |
| Verknüpfung veraltet | Im Ziel „Aktuellen Aufmaßstand übernehmen“, speichern, neu prüfen. |
| Hinweis Doppelerfassung | Gezeichnete und Handzeile vergleichen; „Handzeile entfernen“ oder bewusst behalten. |
| Gezeichnete Flurstücksfläche weicht ab | Kalibrierung und Kontur prüfen; ab 5 % blockiert die Abweichung die Einreichung. |
| Nachweis „Grundlagen geändert“ | Berechnung öffnen, neu berechnen, neuen Nachweisstand erstellen und freigeben. |
| Versionskonflikt | Eingaben bleiben erhalten; mit der Kollegin abstimmen, dann aktuellen Stand laden. |
| Datei extern geändert, App zeigt alten Stand | Externe Arbeitskopie übernehmen oder neue Version importieren. |
| Abgabestand lässt sich nicht festhalten | Genannte Anforderungen, Abweichungen und Aktualität der Nachweise klären. |
| Exportiert, aber nicht als eingereicht angezeigt | Im Portal absenden und den Beleg als Kommunikation/Übermittlung zuordnen. |
| Speichern-Knopf deaktiviert | Rechte, Sperre durch andere Bearbeitung, laufende Aktion oder unveränderter Stand. |
| Formularbibliothek leer | Formularordner unter Einstellungen → Speicherorte prüfen und Vorlagen importieren. |

Für eine Supportanfrage: Programmversion (Statusleiste), Bereich, genaue
Meldung und die Schritte davor nennen. Keine Dateien der verwalteten Ablage
oder Datenbank auf Verdacht löschen.

## Begriffe

| Begriff | Bedeutung |
| --- | --- |
| Projektakte | Alle Daten eines Bauvorhabens; als Projekttab geöffnet |
| Bereich 1 · Ermittlung | Register mit allem, was Werte erzeugt |
| Bereich 2 · Nachweis und Einreichung | Register mit allem, was Werte verarbeitet und ausgibt |
| Flurstück | Katastereinheit mit amtlicher Fläche |
| Baugrundstück / Bezugsfläche | Rechnerische Einheit aus Flurstücken nach Abzügen und Zuschlägen |
| Aufmaß | Messungen auf einer Unterlage oder eigenen Zeichnung |
| Markierung | Einzelne gemessene Fläche, Strecke oder Höhe mit Bedeutung |
| Ausschnitt | Teil eines Planblatts mit eigenem Maßstab |
| Übernahme / Verknüpfung | Messwert in einem Zielfeld, dauerhaft mit der Markierung verbunden |
| Handwert | Von Hand eingegebener Wert ohne Verknüpfung |
| Entwurf | Ungespeicherte Eingabe, ggf. lokal gesichert |
| Berechnung | Bearbeitbarer Ansatz mit Regeln, Quellen und Prüfergebnis |
| Nachweisstand | Archivierter, unveränderlicher Berechnungsstand |
| Freigabe | Fachliche Bürofreigabe eines Nachweisstands |
| Dokument / Version | Fortgeführte Unterlage und ihr konkreter, unveränderlicher Dateistand |
| Kategorie | Fachlicher Zweck einer Unterlage, unabhängig vom Dateiformat |
| Verfahrensakte | Ein behördliches Verfahren mit Behörde und Aktenzeichen |
| Anforderung | Benötigte Unterlage im Verfahren mit Entscheidung und zugeordneter Version |
| Abgabestand | Eingefrorene Auswahl konkreter Versionen für eine Einreichung |
| Portalbereitstellung | Exportierte Dateien für die manuelle Übergabe – noch kein Versand |
| Versand / Eingang | Dokumentierte Übermittlung bzw. bestätigter Zugang |
| Genehmigter Stand | Die im Bescheid ausdrücklich zugeordneten Versionen |

## Abschlusscheckliste

Vor dem Abschluss eines Projekts:

- [ ] Verfahren, Entscheidung und Originalbescheide vollständig dokumentiert.
- [ ] Genehmigte Unterlagenversionen zugeordnet; spätere Änderungen davon
      getrennt.
- [ ] Nachforderungen mit Antwortabgabe und ggf. behördlicher Bestätigung
      nachvollziehbar.
- [ ] Auflagen, Bedingungen und Fristen geprüft; offene Pflichten zugeordnet.
- [ ] Versand- und Eingangsbelege, Schriftverkehr und Anhänge in der Akte.
- [ ] Aktenexport (Suche / Wiedervorlagen → Vollständiger Aktenexport) geprüft.
- [ ] Sicherung erstellt bzw. durch die Administration bestätigt.
